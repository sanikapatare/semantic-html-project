Build Meaningful Web Pages with Semantic HTML

Semantic HTML uses meaningful elements to describe the structure and purpose of content on a webpage.

Instead of using generic containers everywhere, semantic elements make your page easier to understand for developers, browsers, and assistive technologies.

ABOUT

What is Semantic HTML?

Meaningful Structure

Semantic HTML means using HTML elements according to their meaning and purpose.

For example, <header> represents introductory content, <nav> represents navigation, and <footer> represents footer information.

This creates a clear and organized document structure.

Why is Semantic HTML Important?

Semantic elements help developers understand a webpage's structure and provide useful information to browsers and assistive technologies.

Good semantic structure can also make websites easier to maintain.

HTML5

Important Semantic Elements

Here are some of the most commonly used semantic elements in HTML5.

01

<header>

Represents introductory content for a webpage or a section.

02

<nav>

Contains important navigation links used to move through a website.

03

<main>

Contains the primary content of the webpage.

04

<section>

Groups related content into a meaningful section.

05

<article>

Represents independent, self-contained content.

06

<aside>

Contains related information that is separate from the main content.

07

<footer>

Contains footer information for the webpage or a section.

08

<details>

Creates an expandable area containing additional information.

ARTICLES

Semantic HTML in Practice

Creating a Clear Page Structure

Published on October 2, 2026

A well-structured webpage can use a header for introductory information, a nav element for navigation, a main element for the primary content, and a footer for closing information.

Inside the main content, related information can be organized using sections and independent pieces of content can be represented using articles.

Why should developers use semantic elements?

Semantic elements clearly communicate the purpose of different parts of a webpage. This makes the HTML easier to read, understand, and maintain.

What is the difference between section and article?

A section generally groups related content, while an article represents content that can stand on its own as an independent piece.
