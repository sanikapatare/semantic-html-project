# Semantic HTML5 Website

## Internship Task

This project demonstrates the use of HTML5 semantic elements to create a clear and meaningful webpage structure.

## Technologies Used

- HTML5
- CSS3

## Semantic Elements Demonstrated

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`
- `<details>`
- `<summary>`
- `<mark>`
- `<time>`
- `<address>`
